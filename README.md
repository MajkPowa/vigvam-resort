# Vigvam Resort

[Otevřít web](https://majkpowa.github.io/vigvam-resort/) · [English version](https://majkpowa.github.io/vigvam-resort/en/) · [Videoukázka pohybu](https://majkpowa.github.io/vigvam-resort/ukazka-pohybu.mp4)

Sdílený návrh webu resortu v Němčicích u Kolína. Na mapě lze vybrat jednotlivé objekty, v detailu ubytování projít fotografie a otevřít prostorový model. Prostorové plány jsou orientační.

Pobytové, svatební a firemní formuláře na tomto webu připravují e-mail pro recepci. Termín a cenu potvrdí resort. Veřejná prezentace běží na GitHub Pages.
